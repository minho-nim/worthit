# WorthIt — 이거 본전 뽑았나?

구매한 물건, 구독, 멤버십을 얼마나 사용했는지 기록하고 사용 단가와 목표 달성률을 확인하는 웹앱입니다. 데이터는 현재 브라우저의 `localStorage`에 저장됩니다. 설정 화면에서 백업을 내보내고 복원할 수 있습니다.

## 주요 기능

- 소비 항목과 목표 사용 단가 관리
- 날짜별 사용량 기록 및 구독 결제 기간 관리
- 항목별 통계, 분석, 업적 확인
- JSON 백업 내보내기와 복원
- 예시 데이터로 앱 체험

## 실행

필요 환경: Node.js 20.19 이상 또는 22.12 이상

```bash
npm install
npm run dev
```

Vite가 출력하는 로컬 주소를 브라우저에서 여세요.

## 확인 명령

```bash
npm run lint
npm run build
```

## 데이터와 개인정보

계정이나 서버 동기화 기능은 없습니다. 입력한 소비 항목과 사용 기록은 브라우저에 저장되므로, 다른 기기에서 자동으로 공유되지 않습니다. 브라우저 데이터를 지우기 전에 설정 화면에서 백업을 내려받으세요.

## 샘플 체험과 실제 사용

- 실제 사용: `/worthit/` — 기존 저장 키를 유지하며 이 브라우저에 소비를 저장합니다.
- 샘플 체험: `/worthit/?mode=demo` — 메모리에서만 동작하며 새로고침하면 초기화됩니다. 등록·수정·삭제·백업 복원·초기화 모두 실제 저장소와 분리됩니다.
- 체험 화면의 ‘내 소비 시작하기’는 기존 기록으로 돌아갑니다. 실제 기록이 없으면 첫 소비 등록 화면을 엽니다.
- 과거 버전에서 실제 저장소에 불러온 샘플은 사용자 기록과 함께 보존합니다. 자동으로 삭제하지 않습니다.

## 설치형 웹앱

- 실제 사용 화면의 설치 버튼 또는 설치 안내를 이용합니다. 별도 스토어 등록은 필요하지 않습니다.
- 서비스 워커는 `/worthit/` 범위에서 앱 파일을 미리 저장합니다. 최초 온라인 접속과 캐시 준비 후 오프라인으로 사용할 수 있습니다. 외부 글꼴은 연결이 없으면 기본 글꼴로 표시됩니다.
- 새 버전은 화면의 업데이트 안내를 눌러 적용합니다. 작성 중인 폼은 업데이트 전에 저장해야 합니다.
- 실제 기기의 설치와 오프라인 실행은 기기·브라우저별 확인이 필요합니다.

## 나만의 사용 목표

새 등록에서는 만족할 사용 횟수·시간·기간을 먼저 입력합니다. 목표 단가는 구매금액을 그 사용량으로 나누어 계산하며, 추천은 시작 예시로만 제공합니다. 단가 직접 입력도 지원하고 기존 항목의 목표는 보존합니다. 표시 금액은 반올림하지만 계산에는 원래 값을 사용하여 입력한 사용량 목표가 줄지 않게 합니다. 구독의 누적 결제금액이 늘어나면 같은 목표 단가를 유지하는 데 필요한 누적 사용량도 늘어납니다. 일수 방식은 구매일부터 지난 날짜이며 실제 사용을 감지하지 않습니다. 목표 달성은 사용자가 정한 기준이며 실제 절약액이나 객관적인 구매 가치를 판정하지 않습니다.
